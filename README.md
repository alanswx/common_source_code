# Common Source Code Project: macOS and Linux

This is a native macOS port, and a Linux port in progress, of Takeda Toshiya's
[Common Source Code Project](http://takeda-toshiya.my.coocan.jp/) (CSCP). CSCP is
one source tree for about 80 Japanese and other retro computers and consoles. The
base is the upstream release of 11/9/2025. Takeda's `readme.txt` and the
`readme_by_*.txt` files list the machines and their authors.

The port adds:

- A macOS front-end (`src/mac/`): Metal video, CoreAudio sound, menus for disks,
  tapes, Quick Disks and cartridges, ROM alias discovery and a missing-ROM report.
- A Linux front-end (`src/linux/`): an SDL2 window with sound and keyboard.
- Paste Clipboard on both: text is typed one line at a time through the
  machine's auto key, with kana converted to the machine's half-width kana.
- A CMake build of all 128 machine targets: `.app` bundles on macOS, plain
  executables on Linux.
- Headless command-line modes for automated testing and for comparison against
  MiSTer FPGA cores. The headless mode reads the screen back as text, using a
  font it learns from each machine's own display, and runs scripts that wait
  for the BASIC prompt.
- `tool/typein.py`: types a BASIC listing in, lists it back to check every line,
  and saves it to a tape or disk image, which it then loads back and checks.

## Building on macOS

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 8                     # all 128 machines
cmake --build build --target x1 mz700 -j 8   # or only some
open build/mz700.app
```

`CMakeLists.txt` is generated by `tool/generate_cmake.py`. Add or rename targets
there, not in `CMakeLists.txt`.

ROMs are not included. Each app reports the files it is missing at startup and
looks for them in `~/Library/Application Support/CommonSourceCodeProject/<machine>/`.

## Building on Linux

Needs CMake, g++, zlib and SDL2 (`sudo apt install cmake g++ zlib1g-dev
libsdl2-dev` on Ubuntu). Without SDL2 the build has the headless command line
only.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 16
build/fm7                                   # window; ROMs in ~/.local/share/CommonSourceCodeProject/fm7/
build/x1turbo game.d88 --paste listing.txt  # mount by extension, then type a listing
build/fm7 --headless --rom-dir ~/roms/fm7 --out /tmp/fm7-run --stop-at-frame 600 --final-screenshot
```

The window has no menus. Files given on the command line or dropped on the
window are mounted by extension; `--disk-a` .. `--disk-d`, `--tape`, `--qd` and
`--cart` choose the drive. Host keys use Ctrl+Alt so they never reach the
machine: Ctrl+Alt+V pastes the clipboard, +R resets, +T toggles full speed, +S
saves a screenshot, +F (or Alt+Enter) toggles full screen, +Q quits. `--usage`
lists the options.

ROM and media names are matched ignoring case, as on macOS: `fbasic30.rom`
satisfies `FBASIC30.ROM`. The same headless command line gives the same frames
on both systems.

`src/posix/` holds the OSD layer shared by both systems; `src/mac/` and
`src/linux/` add the host's window, sound, PNG writer and `main`.

## Command-line modes

Every machine accepts `--headless`: it runs without a window or audio, with
an explicit ROM directory and a new output directory. Typing, pasted listings,
key presses, resets and disk or tape changes are scheduled by frame number.
Outputs are PNG screenshots, per-frame hashes, traces, memory dumps, saved disk
and tape images, and a one-line JSON result. With `--script` the run waits on the
screen instead of counting frames (`prompt Ok`, `idle 30`), and `text` saves the
screen as UTF-8 text. See [CLI.md](CLI.md), which also covers `tool/typein.py`.

## Roadmap

1. Type-ins: run `tool/typein.py` over the magazine archive. Remaining gaps:
   MZ-700 kana, more machines' save commands, and DLE (dump list editor)
   tapes.
2. Linux: menus or an on-screen panel for media and settings (the window,
   sound, keyboard and paste work).
3. CI on macOS and Linux.

[MISTER_CORE_GAPS.md](MISTER_CORE_GAPS.md) compares the CSCP machines with the
existing MiSTer cores.
